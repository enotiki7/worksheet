# Ассистент преподавателя — wireframe

Desktop wireframe сценариев регистрации, онбординга, главного экрана и подготовки урока.

## Сценарии

- `?scenario=full-onboarding` — с телефона через 4 шага онбординга
- `?scenario=skipped` — пропущенный онбординг, неполный главный экран
- `?scenario=multi-subject` — заполненный профиль с двумя предметами

### Добавление ранее созданных материалов

Три варианта, на каком этапе пользователь может привязать материалы из библиотеки (презентация, рабочий лист, задание, инфографика):

- `?scenario=materials-at-pick` — **вариант A**: на экране выбора урока в КТП (панель в превью справа)
- `?scenario=materials-at-edit` — **вариант B**: при редактировании урока (блок «Добавить из библиотеки»)
- `?scenario=materials-at-workspace` — **вариант C**: в рабочей области после генерации

Общий поток: главный → «Подготовить урок» → сбор профиля (предмет + класс) → выбор урока в КТП → редактирование → генерация → рабочая область.

### Следующий урок (возвращающийся пользователь)

- `?scenario=next-lesson` — пользователь уже создавал урок; на экране выбора урока первый урок «проведён» с иконками материалов, следующий предвыбран с превью

## Экраны

1. Телефон
2. Онбординг 1–4 (split screen)
3. Главный (чат + «Подготовить урок»)
4. Сбор профиля / выбор связки / выбор урока в КТП с превью
5. Редактирование контента урока (цели, план, рефлексия, ДЗ, выбор материалов)
6. Генерация выбранных материалов
7. Рабочая область: цели и план · презентация · задания (редактирование + ИИ-помощник)

Панель «Wireframe» вверху переключает экраны для демо.
