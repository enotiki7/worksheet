# Ассистент преподавателя — wireframe

Desktop wireframe сценариев регистрации, онбординга, главного экрана и подготовки урока.

## Сценарии

- `?scenario=skipped` — пропущенный онбординг, неполный главный экран
- `?scenario=multi-subject` — заполненный профиль с двумя предметами

### Добавление ранее созданных материалов

Два варианта, на каком этапе пользователь может привязать материалы из библиотеки (презентация, рабочий лист, задание, инфографика):

- `?scenario=materials-at-pick` — **вариант A**: на экране подготовки урока (блок в панели тематического плана)
- `?scenario=materials-at-edit` — **вариант B**: при редактировании урока (блок «Добавить из библиотеки»)

Общий поток: главный → «Подготовить урок» → выбор предмета, параллели и урока в тематическом плане → редактирование → генерация → рабочая область.

### Следующий урок (возвращающийся пользователь)

- `?scenario=next-lesson` — пользователь уже создавал урок; на экране подготовки первый урок «проведён» с иконками материалов, следующий предвыбран

## Экраны

1. Телефон
2. Онбординг 1–2 (split screen: роль → предмет и класс)
3. Главный (чат + расписание + «Подготовить урок»)
4. Подготовка урока (предмет + параллель слева, редактируемый тематический план справа) / выбор связки
5. Редактирование контента урока (тип урока, цели, план с таймингами, рефлексия, ДЗ, выбор материалов)
6. Генерация выбранных материалов
7. Рабочая область: цели и план · презентация · задания (редактирование + ИИ-помощник)

Панель «Wireframe» вверху переключает экраны для демо.
