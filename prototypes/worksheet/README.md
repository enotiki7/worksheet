# Worksheet generation flow

Interactive mock of the worksheet flow from the teacher home page to a generated printable worksheet.

**Screens**
- Teacher home page; only the “Рабочий лист” card is interactive
- Worksheet creation modal with generation/manual modes and advanced settings
- Deterministic AI loading state
- Generated worksheet preview
- Worksheet editor with tools and settings
- Browser print preview containing only the worksheet

**Out of scope**
- Real AI generation, uploads, persistence and interactive student assignments
- Fully functional editing tools; they are demonstrative controls
